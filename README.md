##Sobre o Programa 

esse programa é um sistema de academia, onde o cliente da academia que no caso é o aluno, para se registrar na acedmia, ele deve inserir suas informações, como cpf, nome, idade, peso, e apos ele inserir essas informações, o aluno esta pronto para inserir o seu login, que é composto pela senha e pelo email
nesse sistema tbm tem a parte do menu do aluno, onde mostra os treinos do aluno que o personal faz exclusivamente para esse aluno especifico, o aluno também consegue editar seus dados
o sistema da academia obviamente também tem os dados dos personais, onde mostra os treinos que o personal tem que criar, os alunos desse personal e entre outras informações
